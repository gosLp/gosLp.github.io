# Resume files

The verified resume PDFs are stored in this directory using these names:

- `pratheek-shetty-cv.pdf`
- `pratheek-shetty-gpu-systems.pdf`
- `pratheek-shetty-compilers.pdf`
- `pratheek-shetty-software-engineering.pdf`

Replace a document by keeping the corresponding filename. The current entries
are marked available in `src/data/resumes.ts`; set an entry to `false` before
removing its file so the site never renders a broken link.
