# Headshot

Add a square portrait here as `pratheek-shetty.jpg`, then set
`headshot.src` to `"/images/pratheek-shetty.jpg"` in `src/data/site.ts`.

Recommended preparation:

- crop to a square with the face centered;
- use JPEG or WebP at approximately 800 by 800 pixels;
- keep the file below roughly 500 KB;
- use a simple, professional background when possible.
